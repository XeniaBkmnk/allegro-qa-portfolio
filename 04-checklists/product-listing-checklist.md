## Product listing 

1. Page UI
   - [ ] Страница со списком товаров корректно загружается после выполнения поиска.
   - [ ] Отображается заголовок страницы/результатов поиска, соответствующий поисковому запросу.
   - [ ] Список товаров отображается без визуальных ошибок.
   - [ ] Основные элементы страницы не перекрывают друг друга.
   - [ ] Элементы управления списком товаров доступны для взаимодействия.
         
2. Product Cards
   - [ ] Каждая карточка товара отображается полностью.
   - [ ] Изображение товара отображается корректно.
   - [ ] Название товара отображается и не обрезается некорректно.
   - [ ] Карточка товара является кликабельной.
   - [ ] При нажатии на карточку открывается соответствующая страница товара.

3. Product Information
   - [ ] Цена товара отображается корректно.
   - [ ] Валюта отображается корректно.
   - [ ] Информация о продавце отображается, если она предусмотрена карточкой.
   - [ ] Информация о доставке отображается, если она предусмотрена карточкой.
   - [ ] Дополнительная информация о товаре отображается корректно и не содержит визуальных дефектов.

4. Sorting

   - [ ] Доступные варианты сортировки отображаются корректно.
   - [ ] Выбор варианта сортировки изменяет порядок отображения товаров.
   - [ ] После применения сортировки порядок товаров соответствует выбранному критерию.
   - [ ] Повторное изменение способа сортировки корректно обновляет список товаров.
