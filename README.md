# Allegro QA Portfolio

QA testing portfolio project focused primarily on manual testing
with additional API, SQL, performance, accessibility and UI automation testing.

## Application Under Test

Allegro is an e-commerce marketplace available at:

https://allegro.pl/

## Project Goal

The goal of this project is to demonstrate practical QA skills
by testing a real-world e-commerce web application.

The project includes:

- Requirements analysis
- Test planning
- Test design techniques
- Checklists
- Test cases
- Bug reports
- Exploratory testing
- Cross-browser testing
- Responsive testing
- Accessibility testing
- Performance testing
- API testing
- SQL practice
- UI automation

## Testing Approach

The primary focus of this project is manual testing.

Automation is used to cover selected stable regression scenarios.

## Status

Project is under active development.
