## 1. Цель

Цель состоит в оценке качества, удобства использования,
совместимости и надежности выбранных функций веб-приложения Allegro.

## 2. Область применения

Включаются следующие области:

- Поиск
- Список товаров
- Фильтры
- Подробная информация о товаре
- Корзина покупок
- Учетная запись пользователя
- Оформление заказа
- Адаптивный дизайн
- Доступность
- Производительность

## 3. Вне области применения

- Реальные финансовые транзакции
- Деструктивное тестирование безопасности
- Нагрузочное тестирование
- Стресс-тестирование
- Внутреннее тестирование бэкэнда/базы данных

## 4. Типы тестирования

- Функциональное тестирование
- Регрессионное тестирование
- Дымовое тестирование
- Исследовательское тестирование
- Тестирование удобства использования
- Тестирование совместимости
- Тестирование адаптивности
- Тестирование доступности
- Тестирование производительности

## 5. Тестовая среда

Браузеры:
- Google Chrome
- Microsoft Edge
- Mozilla Firefox

Операционная система:
- Windows

## 6. Результаты

- Тестовые примеры
- Контрольные списки
- Отчеты об ошибках
- Отчеты об исследовательском тестировании
- Матрица совместимости
- Доступность отчет
- Отчет о результатах деятельности
