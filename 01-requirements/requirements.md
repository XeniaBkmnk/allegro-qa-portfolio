# Требования

## 1. Поиск

Пользователь должен иметь возможность искать товары, вводя
поисковый запрос.

## 2. Список товаров

Пользователь должен иметь возможность просматривать товары,
и использовать доступные параметры фильтрации и сортировки.

## 3. Подробная информация о товаре

Пользователь должен иметь возможность открыть страницу товара,
и просмотреть информацию о товаре.

## 4. Корзина покупок

Пользователь должен иметь возможность добавлять товары в корзину,
удалять товары и изменять количество.

## 5. Учетная запись пользователя

Пользователь должен иметь доступ к функциям, связанным с учетной записью.

## 6. Оформление заказа

Пользователь должен иметь возможность пройти весь процесс покупки.

## 7. Доставка

Пользователь должен иметь возможность выбрать доступный способ доставки.

## 8. Адаптивный веб-дизайн

Основной функционал должен оставаться доступным
на экранах разных размеров.
