## TC-SEARCH-001

 Заголовок: 
- Поиск существующего продукта

Предварительное условие: 
- Пользователь находится на главной страница Allegro

Шаги: 
1. Введите действительное название продукта
2. Нажмите "szukaj"
   
Ожидаемый результат:
- Отображаются результаты поиска, соответствующие введенной фразе   

## TC-SEARCH-002

Заголовок:
- Поиск с пустым вводом

Шаги:
1. Оставить поле ввода пустым
2. Нажать кнопку "szukaj"
 
  Ожидаемый результат:
  - Система обрабатывает пустой поиск и показывает все элементы

## TC-SEARCH-003

Заголовок:
  - Поиск после отчистки ввода

Шаги:
1. В поле ввода ввести название продукта
2. Нажать "szukaj"
3. Отчистить поле ввода
4. Нажать "szukaj"
   
Ожидаемый результат:
  - Поле ввода чистое, остается предыдущая страница поиска 

## TC-SEARCH-004

Заголовок:
- Поиск после изменения запроса

Шаги:
1. В поле ввода вести название продукта например 'bajki'
2. Наблюдать результаты поиска по введенному запросу
3. Очистить поле поиска полностью или изменить текст на новый, например 'zeszyt'
4. Нажать на кнопку "szukaj" или дождаться автоматической подгрузки результатов (если предусмотрено системой)

Ожидаемый результат:
- Поле поиска отображает новый текст запроса 
- Список товаров обновляется и соответствует новому запросу

## TC-SEARCH-005

Заголовок:
- Поиск с одной буквой
  
Предварительное условие: 
- Пользователь находится на главной страница Allegro

Шаги:
1. В поле ввода ввести одну например, например "u"
2. Нажать "szukaj"

Ожидаемый результат:
- Отображаются все релевантные результаты содержащие эту букву
- Если работает "автоподсказка", показываются подходящие варианты по мере ввода буквы

    ## TC-SEARCH-008

   Заголовок:
- Поиск с пустым полем ввода

  Предварительное условия:
- Пользователь находится на главной страница Allegro

  Шаги:
1. В поле ввода ничего не вводить
2. Нажать "szukaj"

   Ожидаемый результат:
-  Система предупреждает пользователя, что поле поиска не может быть пустым
-  Система считает пустой запрос некорректным и отображает страницу с сообщением "Результатов не найдено"
